# Синхронизация Litestar с Polestar

Litestar берёт у Polestar только **контент**: гайды, Codex, базы заданий и
предметов, карты маршрутов, русские тексты и названия гайдов. Код Litestar
(движок и интерфейс) синхронизация не трогает.

## Что нужно

- Node 24
- Lua 5.1 (`luajit` или `lua5.1`) для проверки гайдов
- git, рабочее дерево без незакоммиченных изменений
- remote `polestar` (один раз):

  ```sh
  git remote add polestar https://github.com/fitzforge/polestar.git
  ```

## Обычная синхронизация

```sh
node tools/litestar.js sync              # последний релиз Polestar
node tools/litestar.js sync v0.4.0.2     # конкретный релиз
```

Что происходит:

1. Скачивается zip релиза с GitHub, проверяется его SHA256.
2. Формат каждого пакета гайдов (`X-Polestar-Format`) сверяется с тем, что
   читает движок Litestar (`Guides.FORMATS` в `addon/Polestar/Core/Guides.lua`).
   Если формат новее, синхронизация останавливается и ничего не меняет
   (код выхода 3). Тогда нужен перенос движка, см. ниже.
3. Заменяются папки данных: `Polestar_Guides*`, `Polestar_Nav*`,
   `Polestar_ItemDB`, Codex, QuestDB, а в `Polestar_ruRU` тексты и названия.
   `Polestar_ruRU/Interface.lua` (строки интерфейса Litestar) остаётся нашим.
4. Сборка и проверка: персонажи обеих фракций, английский и русский клиент,
   проход по всем гайдам прокачки. При ошибке контент возвращается как был,
   коммита и установки нет.
5. Коммит и установка в игру.

Повторный запуск на той же версии ничего не меняет.

Флаги:

| Флаг | Что делает |
|---|---|
| `--no-install` | не копировать в папку игры |
| `--force` | взять гайды новее движка (только для проверки, в игре они не загрузятся) |

После установки игру нужно **полностью перезапустить**: `/reload` не
подхватывает новые файлы.

## Перенос движка (редко)

Нужен, только когда Polestar меняет формат гайдов (так было в 0.4.0) и
обычный `sync` останавливается с кодом 3.

```sh
node tools/litestar.js sync v0.5.0 --engine
```

- Сливает код релиза в текущую ветку, оставляет только то, что в списке
  KEEP (`tools/litestar/sync.js`), и снова удаляет вырезанное (CUT).
- Наши файлы (README, AGENTS, `.gitignore`, `package.json`, русский
  `Interface.lua`) в конфликте остаются нашими.
- На строках, которые поменяли обе стороны, останавливается (код выхода 2).
  Тогда исправить конфликты, `git commit`, потом `node tools/litestar.js sync v0.5.0`.
- Отменить незавершённое слияние: `git merge --abort`.

Удобно делать перенос в отдельной ветке и сливать её после проверки.

После переноса:

```sh
node tools/litestar.js i18n sync     # новые строки интерфейса
node tools/litestar.js i18n todo     # что осталось перевести в addon/Polestar_ruRU/Interface.lua
node tools/litestar.js build && node tools/litestar.js check
```

## Чего не делать

- Не править папки данных руками: `sync` их заменит.
- Код менять только в `addon/Polestar/`, оставляя имена Polestar:
  `tools/litestar/build.js` переименовывает всё в Litestar при сборке.
- Файл вне списка KEEP в `tools/litestar/sync.js` удаляется при следующей
  синхронизации. Новый файл в корне репозитория нужно добавить в KEEP.
